## Conventions

- Problems are grouped by LeetCode difficulty.
- Problem folders use `0000-kebab-case-title` naming.
- Main solution files use language-specific names such as `Solution.java`, `solution.py`, or `solution.cpp`.
- Each classified problem includes a `README.md` and `metadata.json`.
- Files that cannot be confidently matched to a LeetCode problem are kept in `uncategorized/` with an explanation.
